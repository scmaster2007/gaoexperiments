# AIXI Experiments

Experiments on what prior / inductive bias trained networks actually implement.

```
aixi/          Exact Solomonoff-style prior vs. trained transformers (experiments 1–4). See aixi/README.md.
experiments/   Quick follow-up experiments on hypotheses from thoughts/papers.md
thoughts/      Reading notes and open questions
```

Scripts in `aixi/` use paths relative to that folder, so run them from inside it (e.g. `cd aixi && python3 src/analyze.py`).
